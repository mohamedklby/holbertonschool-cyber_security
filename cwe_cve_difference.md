CWE (Common Weakness Enumeration) est une liste de types de faiblesses générales dans les logiciels (ex: mauvaise validation d’entrée, SQL injection).
Le Common Vulnerabilities and Exposures, lui, identifie des vulnérabilités spécifiques et réelles dans des systèmes ou logiciels précis.

👉 Différence :

CWE = catégorie de faiblesse
CVE = vulnérabilité concrète avec un ID unique
