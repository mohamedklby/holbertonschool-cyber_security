The vulnerability CVE-2021-34527, also known as PrintNightmare, is a remote code execution flaw in the Windows Print Spooler service.

It allows an attacker to execute arbitrary code on a system with SYSTEM privileges without authentication, potentially leading to full system compromise.

Severity
Severity rating: Critical
CVSS score: High (around 8.8–9.8 depending on configuration)
Impact
Remote code execution
Full system takeover
Data modification or deletion
Creation of new administrator accounts
Mitigation
Apply Microsoft security patches immediately
Disable Print Spooler service if not needed
Restrict access to printer services
Monitor for suspicious activity
Apply least privilege policies
