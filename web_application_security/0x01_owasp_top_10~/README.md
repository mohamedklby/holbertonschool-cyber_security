📌 Project Overview

This project is part of the Holberton School Cyber Security curriculum and focuses on the OWASP Top 10 (2021) — the most critical web application security risks.

The goal is to understand, identify, exploit, and reason about common web vulnerabilities through hands-on challenges on a vulnerable web application.

Each task simulates real-world attack scenarios and teaches how attackers exploit poor design, weak cryptography, broken access control, and injection flaws.
